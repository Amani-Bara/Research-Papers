# 📚 Research Papers by Amani Albarazi

This repository contains my co-authored research papers across AI, IoT, Security, Healthcare, and Emerging Technologies. Each paper is available in PDF format for direct access.

---

## 📄 Papers

### 1. [Virtual Reality Technologies for Saudi Museums (2024)](./Virtual_Reality_in_Museums_V2.pdf)  
Co-authored a qualitative and quantitative research study exploring the best VR technologies 
to enhance cultural heritage experiences in Saudi museums. Evaluated 3D scanning, 
AI-enhanced VR, and gesture-tracking solutions.  

**Tags:** Virtual Reality, Museums, Cultural Heritage  

---

### 2. [AI-Powered Image-Based Diagnostics in Healthcare (2024)](./AI-Powered%20Image-Based%20Diagnostics.pdf)  
Analyzed the benefits of AI-powered image diagnostics for improving healthcare accuracy 
and efficiency. Highlights improvements in early disease detection, cost reduction, 
and ethical challenges.  

**Tags:** Artificial Intelligence, Healthcare, Diagnostics  

---

### 3. [Greedy Algorithms for Routing in Parallel Computing Systems (2024)](./Greedy%20Algorithms.pdf)  
Explored greedy routing algorithms in parallel computing networks. Demonstrated efficiency 
in packet routing with **O(log N)** delay and minimal queue sizes under average conditions.  

**Tags:** Algorithms, Networking, Parallel Computing  

---

### 4. [IoT in Motion: Advancements in Urban Mobility and Smart Transportation (2024)](./IoT_in_Motion_Advancements_in_Urban_Mobility.pdf)  
Investigated IoT applications in urban mobility and smart transportation. Topics include 
intelligent traffic systems, smart parking, and V2X communication.  

**Tags:** IoT, Smart Cities, Urban Mobility  

---

### 5. [Secure Code Review and Static Analysis Tools (2024)](./Secure%20Code%20Review%20and%20Static%20Analysis%20Tools.pdf)  
Studied secure code review practices and static analysis tools. Evaluated effectiveness 
in detecting vulnerabilities, reducing false positives, and integrating into DevSecOps pipelines.  

**Tags:** Software Security, Static Analysis, Secure Development  

---

### 6. [Federated Unlearning Framework for Privacy-Preserving Inter-Hospital Healthcare Networks in Smart Cities (2025)](./Federated_Unlearning_Framework_for_Healthcare_Networks.pdf)

Co-authored a research paper proposing a federated unlearning framework for privacy-preserving healthcare networks in smart cities. The study explores secure machine learning techniques that enable hospitals to collaboratively train AI models while allowing sensitive data to be effectively removed when required, supporting regulatory compliance and patient privacy.

**Reference Implementation:** https://github.com/farhussaini/adv-hybrid-system

**Tags:** Federated Learning, Machine Learning, Healthcare AI, Privacy, Smart Cities, Data Security
